# Auto-Calibration 방안 2 — Feature Matching 기반 캘리브레이션

Preset마다 개별 캘리브레이션하던 방식을 넘어, **임의의 PTZ 자세에서 그 순간의 카메라 파라미터(`R`, `t`, `K`, `distCoeffs`)와 지면 homography를 재구성**하는 것이 목표다. 미리 캘리브레이션되지 않은 자세에서도 좌표 변환이 가능해지고, preset에 얽매이지 않는 좌표계를 확보할 수 있다.

이 저장소는 그중 **방안 2**를 다룬다. [PTZ-Calib (ICRA 2025)](https://arxiv.org/pdf/2502.09075)에서 착안해 매칭점 기반으로 캘리브레이션을 수행한다. 신규 모델을 만드는 것이 아니라, **알고리즘 재구현과 정확도 재현 검증**이 범위다. 구현은 [`ptz_calib_dy/`](ptz_calib_dy/README.md)에 있다.

## 두 방안

**방안 1** — few-shot PTZ 동적 calibration *(별도)*

- Pan·Tilt 축과 게인을 캘리브레이션해 `R`, `t`를 계산한다.
- Zoom과 내부 파라미터의 관계를 회귀 적합해 `K`를 계산한다.
- 실시간 카메라 뷰에서 P, T, Z를 입력해 월드 좌표 변환을 눈으로 검증한다.

**방안 2** — feature matching 기반 auto-calibration *(이 저장소)*

- 레퍼런스 프레임과 현재 프레임의 특징점 매칭으로 `K`, `R`, `t`, `dist`를 추정한다.
- PTZ 역학 모델을 쓰지 않으므로, 임의의 자세에서도 매칭만 되면 캘리브레이션이 가능하다.

## Homography를 구하는 두 경로

방안 1은 점 대응으로 $H$를 계산하고, 방안 2는 카메라 모델로 $H$를 추정할 수 있다. 둘 다 결과는 Homography $H$다.

| 구분 | 카메라 모델 | 점 대응 |
| --- | --- | --- |
| $H$를 어떻게 구함? | $H = K_j R_j R_i^{\top} K_i^{-1}$ | `cv2.findHomography()` |
| 방식 | 캘리브레이션 기반 | 체커보드 / 키포인트 기반 |
| 필요한 것 | $K_i, K_j, R_i, R_j$ | 대응점 $p_i \leftrightarrow p_j$ |
| RANSAC | 불가 | 가능 |
| 노이즈 영향 | 파라미터 오차가 직접 전파 | 대응점 품질에 좌우 |
| 카메라 회전 정보 | 필요 | 불필요 |
